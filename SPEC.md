# Portfolio Specification

## 1. Overview
- **Who**: Game Designer (systems, mechanics, economies)
- **Goal**: Job applications, showcase work to studios/clients
- **Style**: Minimal — clean, professional, lots of whitespace

## 2. Sections

| Section | Description |
|--------|-------------|
| **Hero** | Name, title, tagline, CTA buttons |
| **Work** | 4 Project cards (grid) → click → separate Case Study page |
| **About** | Bio, photo (placeholder), skills, education |
| **Case Studies** | Separate pages per project |
| **Contact** | Email, LinkedIn, Twitter, CV download link, availability status |

## 3. Case Study Page Structure

| Field | Description |
|-------|-------------|
| Overview | What the project is |
| My Role | Your specific contribution |
| Images/Gallery | Screenshots, key art |
| Challenges & Solutions | Problems faced and how you solved them |
| Results/Feedback | Outcomes, awards, quotes |
| Tools Used | Unity, Unreal, Figma, etc. |

## 4. Visual Style
- **Minimal** — lots of whitespace, clean typography
- **Colors**: Dark theme (customizable via editor)
- **Font**: Clean sans-serif (changeable)
- **Layout**: 2-column grid (projects), single column mobile

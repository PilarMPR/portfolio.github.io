What is Create Your Own Monster?

A family-friendly F2P mobile game developed at Mechanic Games for ages 6–12. The concept rests on two interlocking pillars: deep character customisation to create emotional attachment, and diverse minigames to drive progression.

"You care about winning minigames because the monster is yours. Without the customisation, the progression has no emotional anchor."
How it works

Core Loop

Customise monster→Play minigame→Earn resources→Level up→Unlock more
My responsibilities

What I Contributed

  • Designed multiple distinct minigames, each with a unique core mechanic to prevent session fatigue.
  • Balanced and iterated on mechanics and level design in Unity across the full 6–12 age range.
  • Created structured documentation in Google Docs, Sheets, Miro, Trello, and Adobe XD.
Key decisions & learnings

Challenges

Designing for ages 6–12 is a wider accessibility band than almost any other demographic. Every minigame had to be immediately readable without tutorial text — pure visual communication — while still engaging for older players.

Each minigame needed a sufficiently distinct core action — not just a reskin — so choosing between them felt like selecting from a menu, not repeating the same loop with different wallpaper.
